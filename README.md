# Kodeks International landing page

Static landing page for Kodeks Solutions. Plain HTML and CSS, no build step and no dependencies. Open `index.html` in a browser, or drop the files on any static host.

## Structure

- `index.html` the page
- `styles.css` all styles
- `logos/` vendor logos
- `og-image.png`, `favicon.ico`, `apple-touch-icon.png` social and browser icons
- `robots.txt`, `sitemap.xml` SEO

## Deploy

Copy every file into the web root, keeping the folder flat. Step by step notes are in `DEPLOY.txt`.

Live: https://kodeksintlt.netlify.app
